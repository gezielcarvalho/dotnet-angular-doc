# Project charter

## Purpose

`dotnet-angular-doc` is a full-stack educational and portfolio showcase for
catalog-style management capabilities. It demonstrates a .NET 8 Web API,
Angular 17 standalone frontend, Entity Framework Core with SQL Server, Docker,
and backend testing in one runnable solution.

## Stakeholders and users

| Group | Need / responsibility |
| --- | --- |
| Portfolio reviewer | Understand the full-stack architecture and delivery practices quickly |
| Developer / contributor | Run, test, and extend the application safely |
| Project owner | Keep the showcase accurate, demonstrable, and maintainable |

## Success criteria

- [ ] The solution can be understood and run from the README.
- [ ] The architecture and quality approach are clear without reading all source files.
- [ ] The repository remains an honest demonstration project, with scope and limitations explicit.

## Constraints

- This repository is for educational and demonstration purposes.
- Application behavior, deployment, and dependencies are out of scope for this documentation baseline.
- Historical material under `docs/legacy/` remains preserved and may not reflect the current code exactly.
