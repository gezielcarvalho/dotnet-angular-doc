# Historical project material

This directory was moved from the repository's former `doc/` root on
2026-10-11. Its files are retained for learning, traceability, and historical
context; they are **not the current source of truth**.

## Contents

- `project-edm/`: draft Electronic Document Management design notes.
- `deployment/`: historical Docker Swarm, Jenkins, Nginx, Firebase, backup,
  and deployment artifacts.
- Root diagrams and troubleshooting notes: prior modeling and environment work.

## Safe use

- Start with the parent `docs/` documents for the current project context.
- Do not execute scripts or follow deployment instructions here without a new,
  approved infrastructure review.
- Treat server details, endpoints, passwords, tokens, and configuration values
  as examples or stale references unless they are independently verified.
- Historical links may point to paths or resources that no longer exist.
