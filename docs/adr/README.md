# Architecture decision records

Use an ADR only when a decision changes a meaningful technical, operational, or
security trade-off. Keep accepted ADRs short and immutable.

```text
# ADR-001: <decision title>

## Status
Proposed | Accepted | Superseded

## Context
What requires a decision?

## Decision
What was chosen?

## Consequences
What becomes easier, harder, riskier, or deferred?
```
